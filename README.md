### Full-Stack, building B2B data and automation platforms

I design, build and run SaaS products end to end: the database, the API, the app, the browser extension, the cloud it runs on and the bill at the end of the month. Most of my work lives in private repositories, so the contribution graph is the best view of it.

**What I build**

- **Data platforms**: multi-node ClickHouse clusters for large-scale analytics, Postgres for the core product, BigQuery for logs and reporting, with query tuning, materialized views and safe migrations
- **APIs and integrations**: public REST APIs with OpenAPI docs, webhooks, Gmail and Outlook inbox sync, CRM sync, Stripe billing, Zapier apps
- **AI automation**: LLM steps inside customer workflows, and MCP servers that let AI agents read and write real product data
- **Web apps**: fast, data-heavy dashboards and tables, inboxes and workflow builders
- **Browser extensions**: Chrome extensions (Manifest V3) that bring an app's data and actions into the pages people already use
- **Cloud and DevOps**: Google Cloud from Terraform, containerized services, background job queues, CI pipelines, monitoring and cost reduction
